# Sistema de Comandas - C#

Projeto desenvolvido em C# com o objetivo de simular o funcionamento de comandas em um restaurante, permitindo criar e gerenciar pedidos associados a mesas.

## 🚀 Funcionalidades
- Criar comandas para mesas específicas
- Armazenar produtos adicionados na comanda
- Controlar se a comanda está aberta ou fechada
- Estrutura inicial para gerenciamento de pedidos

## 🛠️ Tecnologias utilizadas
- C#
- .NET
- Programação orientada a objetos (POO)
- Listas e coleções (`List<T>`)
- Estruturação de classes e entidades do sistema

## 📌 Estrutura do projeto
O projeto possui classes principais como:

- **Comanda**
  - Número da mesa
  - Status (aberta/fechada)
  - Lista de produtos associados

- **Produto**
  - Nome
  - Preço
  - Quantidade
  - Subtotal

## ▶️ Como executar
1. Clone este repositório
2. Abra no Visual Studio ou VS Code
3. Execute o projeto pelo terminal

## 🎯 Objetivo do projeto
Este projeto foi criado com foco em aprendizado, praticando:

- Modelagem de um sistema real (restaurante)

- Estrutura base para um futuro sistema completo com:
  - Banco de dados
